# Plan de Tareas: fetchmark-v2

## Resumen Ejecutivo del Plan

Este documento establece la secuencia atómica y detallada de tareas requeridas para el desarrollo, prueba y despliegue ONE SHOT en producción de **fetchmark-v2**.

El plan se organiza en 5 fases secuenciales estrictamente ordenadas:

- **Fase 0: Infraestructura ONE SHOT**: Configuración de enrutamiento Vercel, variables de entorno y preparación del proyecto.
- **Fase 1: Capa de Datos**: Definición de esquema Prisma PostgreSQL para Supabase con Supavisor Pooler y cliente Singleton.
- **Fase 2: Seguridad y Serverless BFF**: Middleware JWT, rutas de autenticación Google OAuth2, CRUDs aislados por `userId` y microservicio de scraping OpenGraph con Cheerio.
- **Fase 3: Sistema de Diseño UI**: Configuración de Tailwind CSS, diccionario de tokens UI, componentes átomos, moléculas, skeletons y microinteracciones.
- **Fase 4: Ensamblaje Frontend**: Interfaces TypeScript, servicios Angular 22 con Signals, AuthGuard, AuthInterceptor, organismos UI, templates, páginas y enrutamiento.
